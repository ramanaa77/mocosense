# MocoSense

MocoSense is a Flutter app that checks basic device security posture and clipboard safety. It can detect common indicators such as root/jailbreak status, emulator environment, developer mode, device authentication support, and biometric availability, and it includes a simple clipboard check/clear flow. The app also supports light and dark themes and stores the theme preference locally. It is a small demo-style project focused on Android security signals and UI feedback rather than a full production security solution.

- Device posture audit for root, emulator, developer mode, and biometric checks
- Clipboard status check and clear action
- Light/dark theme toggle with saved preference
- Built with Flutter and Riverpod
